# apartment-rental

لتأجير الشقق ومتابعة الحجوزات

## البيانات

- `data/apartments.json` — بيانات الشقق المتاحة للتأجير: النوع، الغرف، الموقع، الأسعار، مدة العقد، أوقات الدخول/الخروج، والمرافق.

## المصدر

الملفات الأصلية لهذا المشروع محفوظة في مجلد Google Drive "RentApartment"، وتُنقل من هناك إلى هذا الريبو عند إضافتها أو تحديثها.
